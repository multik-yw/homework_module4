# Проект Homework_module4

## Описание:
Разработка приложения для анализа банковских операций клиента.

## Установка проекта:
1. Клонировать репозиторий:
- https://github.com/multik-yw/homework_module4
2. Установите зависимости:
- pip install -r requirements.txt

## Структура проекта:
1. Созданы классы Product и Category
2. Добавлена инициализация
3. Изменен тип атрибута с продуктами на приватный.
4. Добавлен геттер для класса Category для вывода товаров.
5. Добавлен класс-метод для создания нового товара.
6. Созданы два класса наследников класса Product : «Смартфон» (Smartphone) и «Трава газонная» (LawnGrass)
7. Класс «Смартфон» (Smartphone) расширен атрибутами: производительность, модель, объем встроенной памяти, цвет
8. Класс «Трава газонная» расширен атрибутами: страна-производитель, срок прорастания, цвет
9. Добавлена возможность сложения по общей сумме для продуктов одной группы

## Тестирование проекта
Все тесты находятся в директории "test". 
В папке "htmlcov" в файле "index.html" находится отчет по тестированию проекта в HTML.
